# INVOICE TYPE IDENTIFICATION FIX PLAN
## Inventory & Ledger System Enhancement

### PROBLEM STATEMENT
The Sales Report page does not identify or distinguish between different invoice types (sale/purchase/cr note/dr note), making it difficult for users to understand the nature of each transaction.

### CURRENT STATE ANALYSIS
- Database: bills table has 'btype' column storing transaction types (SALES, PURCHASE, etc.)
- Frontend: sales-report.js renders all bills uniformly without type indication
- UI: Missing visual distinction between different invoice types

### ROOT CAUSE
The sales report table in sales-report.ejs and its JavaScript handler do not include an invoice type column or indicator.

- Update the bill data mapping to include normalized invoice type labels
- Create a mapping function to convert raw btype values to user-friendly labels

### TECHNICAL SPECIFICATIONS

#### Invoice Type Mapping Function:
```javascript
function getInvoiceTypeLabel(btype) {
    const typeMap = {
        'SALES': { label: 'Sales', class: 'bg-green-100 text-green-800' },
        'PURCHASE': { label: 'Purchase', class: 'bg-blue-100 text-blue-800' },
        'CREDIT NOTE': { label: 'Credit Note', class: 'bg-yellow-100 text-yellow-800' },
        'DEBIT NOTE': { label: 'Debit Note', class: 'bg-red-100 text-red-800' },
        'SALES RETURN': { label: 'Sales Return', class: 'bg-purple-100 text-purple-800' },
        'PURCHASE RETURN': { label: 'Purchase Return', class: 'bg-indigo-100 text-indigo-800' },
        'INTER-STATE SALES': { label: 'Inter-State Sales', class: 'bg-green-100 text-green-800' },
        'INTRA-STATE SALES': { label: 'Intra-State Sales', class: 'bg-teal-100 text-teal-800' },
        'INTER-STATE PURCHASE': { label: 'Inter-State Purchase', class: 'bg-blue-100 text-blue-800' },
        'INTRA-STATE PURCHASE': { label: 'Intra-State Purchase', class: 'bg-cyan-100 text-cyan-800' }
    };
    
    const normalizedType = (btype || '').toUpperCase().trim();
    const match = Object.keys(typeMap).find(key => 
        normalizedType.includes(key) || key.includes(normalizedType)
    );
    
    return match ? typeMap[match] : { label: btype || 'Unknown', class: 'bg-gray-100 text-gray-800' };
}
```

#### Updated renderReport Function Logic:
